# Mind Games — учебный сайт

Сайт о психологических триллерах. Проект создан для задания по HTML, CSS, DOM и JavaScript.

**Посмотреть сайт:** https://bcbxjoin-boop.github.io/mind-games/

## Как открыть

Откройте `index.html` в браузере. Также можно открыть папку проекта в VS Code и использовать расширение Live Server.

Для загрузки фотографий из Wikimedia Commons и отправки учебных форм требуется интернет.

## Страницы

- `index.html` — главная страница, списки и ссылки на разделы
- `genre.html` — описание жанра и вложенный список
- `films.html` — подборка фильмов и таблица с фоном и ссылками
- `gallery.html` — галерея с подписями и миниатюрой
- `big-image.html` — изображение 600 × 400 в отдельной вкладке
- `forms.html` — контактная анкета и выбор фильма
- `passport.html` — изменение данных учебного макета паспорта по нажатию
- `dom.html` — чтение данных через DOM и скриншот консоли
- `task.html` — задача № 1015 и отправка условия, числа A и результата

## Структура файлов

- `style.css` — оформление: белый, фиолетовый и чёрный цвета
- `scripts/passport.js` — переключение кириллицы и латиницы
- `scripts/dom.js` — считывание данных из DOM
- `scripts/task.js` — вычисление результата по условию
- `images/` — используемые локальные изображения, включая фон таблицы и изображения фильмов

## Проверка

1. Проверьте ссылки в меню и переходы по закладкам.
2. На странице «Галерея» нажмите на маленькую картинку: большое изображение должно открыться в новой вкладке.
3. На странице «Анкеты» отправьте обе формы: сервис `https://httpbin.org/post` отображает полученные поля.
4. На странице «Паспорт» нажмите «Изменить язык» и нажмите ещё раз, чтобы вернуть кириллицу.
5. На странице DOM нажмите «Получить данные из DOM» и проверьте фамилию, имя и год рождения.
6. На странице «Задача» проверьте A = 10 (X = 109) и A = 62 (X ≈ 253.00026). Затем отправьте условие и результат через POST.

Формы являются учебными. Не вводите настоящие пароли или конфиденциальные данные.
