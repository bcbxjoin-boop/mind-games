MIND GAMES - УЧЕБНЫЙ САЙТ

Как открыть: дважды нажать на index.html. Для переходов используется меню на каждой странице.
Чтобы отправить формы, требуется подключение к интернету. Они отправляют тестовые данные на https://httpbin.org/post методом POST.

Страницы:
index.html - главная страница
 genre.html - особенности жанра и вложенные списки
 films.html - подборка фильмов, таблица с фоном, изображением и внешними ссылками
 gallery.html - галерея и миниатюра
 big-image.html - большое изображение в отдельной вкладке
 forms.html - две формы
 passport.html - изменение кириллицы по клику
 dom.html - паспорт и скриншот консоли DOM
 task.html - решение задачи 1015

Что объяснить на защите:
- HTML содержит содержание и ссылки. href указывает, куда перейти.
- Атрибут id задаёт имя элемента, getElementById находит его в DOM.
- CSS задаёт фон, цвет, отступы и выделение текущей страницы.
- addEventListener('click', ...) запускает функцию после нажатия.
- if/else в task.js выбирает формулу при A < 62 и A >= 62.
- Number() превращает строку из поля ввода в число.
- В формах name - имя отправляемого параметра, action - адрес сервера, method="post" - способ отправки.
- Значения из password в учебной форме нельзя использовать как реальные пароли.

Паспорт: учебный макет, данные документа вымышлены. Реальные только фамилия, имя и год рождения по условию задания.
Изображения сделаны для учебного сайта и сохранены локально в папке images.

ВАЖНО: скриншот DevTools нужно снять вручную на вашем ПК перед сдачей.
1. Откройте dom.html в Chrome, нажмите F12, выберите Console.
2. По очереди выполните три команды, указанные прямо на странице.
3. Сохраните снимок окна браузера под именем images/dom-console.png,
   заменив текущий скриншот браузера на скриншот с открытой консолью.
Причина: в окружении сборки DevTools не открываются, хотя чтение DOM протестировано.
