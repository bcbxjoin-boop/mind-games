Решение алгоритмической задачи № 1015

Дано вещественное число A. Нужно вычислить X по одной из двух формул:

  • Если A меньше 62, то X = A2 + 4 + 5.
  • Иначе X = 1 / A2 + 4 * A + 5.

Введите любое вещественное число, например 10, 62 или 62.5.

После нажатия будет показана выбранная формула.

При A = 10 должно получиться X = 109. При A = 62 используется вторая формула.
